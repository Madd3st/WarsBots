# Ограничения и нерешённые вопросы

| Риск | Подтверждение / неизвестное | Следующий способ проверки |
| --- | --- | --- |
| Нет подтверждённой сборки | CMake/MSVC не найдены; конфигурация не стартовала | Чистый SDK, затем WarsBots на MSVC, логи и проверка CreateGame |
| Нет проверенной runtime-среды | Найдены установочные материалы, не рабочая Wars 1.5 | Полная установка, dedicated + реальные клиенты |
| Виртуальный игрок не равен актёру | IsPlayer зависит от канала, перечисление игроков — m_channelIds | Изолированный probe, затем отдельная регистрация по EntityId |
| Падение при fake connect | ServerSynchedStorage разыменовывает отсутствующий net channel | Не использовать этот путь; не подделывать соединение |
| Закрытый CryAction/CryNetwork | CreateActor и network binding доступны только через интерфейсы | Проверка server-owned actor, late join и удаления |
| Input authority и physics | eEA_GameClientDynamic и AI-dependent prephysics | Тест движения dedicated с двумя клиентами и задержкой |
| CryAI в MP | Co-op использует глобальное переключение multiplayer | Первоначально собственные waypoints; CryAI исследовать отдельно |
| Lua 1.5 не изучены | IA/PS скриптов нет в проверенном SDK | Прочитать локальные игровые скрипты, не коммитить ресурсы |
| Смерть/очки/PS | RMI, storage, team/channel maps и Lua связаны | Проверять весь lifecycle, scoreboard и PP, не только actor health |
| Клиентская совместимость | Не доказана для модифицированного сервера | Проверить обычный и модифицированный клиенты отдельно |
| Legacy ABI/toolchain | Интерфейсы рассчитаны на бинарный CryEngine 2 | Не менять virtual layout; отдельные x86/x64 сборки |
| Лицензия | Crytek Limited License, нет явных лицензий референсов | Сохранять LICENSE/notices, не переносить чужой код без разбора условий |
| OneDrive и пути | Workspace содержит пробелы/кириллицу, синхронизацию | При ошибках инструментов воспроизвести в коротком локальном пути; пока это риск, не обнаруженный дефект |

Не реализованы: игроки-боты, навигация, бой, respawn ботов, scoreboard ботов,
захват объектов, покупки, транспорт. Лог bootstrap не свидетельствует об их наличии.
Никакие engine hacks, выключение cheat protection и глобальные MP-переключения не внесены.
