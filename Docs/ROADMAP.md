# План разработки

## 0. Завершить подтверждение каркаса

Установить MSVC/Windows SDK/CMake/Ninja, собрать чистый SDK, затем WarsBots.
Установить полную Wars 1.5; выполнить клиентский и dedicated smoke test из BUILD.
Критерий: DLL с CreateGame, успешная загрузка, один initialization log на CGame,
штатная игра людей в IA/PS, нормальное завершение. Сейчас этот этап не закрыт.

## 1. Следующая задача: один неподвижный серверный актёр

После этапа 0 добавить явно включаемую диагностическую server-only команду создания
одного `Player` без соединения и отдельную команду удаления. Начать с исследования
CreateActor с channelId=0, не вызывать OnClientConnect и не выделять выдуманный канал.
Создавать только при активных GameRules/загруженной карте; запретить повторный probe,
проверять результат и очищать EntityId при удалении/смене карты.

Логировать EntityId, channelId, IsPlayer, наличие Inventory, physics, movement controller,
результат создания. Проверить на dedicated с двумя клиентами, включая поздний вход:
видимость/позиция, отсутствие падений, удаление, повторный спавн и смена карты.
Если binding не работает, зафиксировать журнал и точную точку отказа; не выдавать
локального видимого актёра за сетевого игрока. Это ещё не полный бот и не scoreboard.

## 2. Участник Instant Action

Изучить Lua именно Wars 1.5. Определить минимальные изменения GameRules для реестра
ботов по EntityId, GetPlayers/GetPlayerCount, смерти, очков и respawn; не регистрировать
ботов в таблицах соединений. Проверить две bot entities, смерть от человека,
начисление очков, повторный respawn и очистку статистики при удалении.

## 3. Движение и репликация

Ввести BotController и проверенный server input path, короткий waypoint-маршрут.
Проверить отсутствие timeout, согласованность физики и анимации у двух клиентов,
late join, stance, sprint, stop, задержку сети. Только затем обобщать навигацию.

## 4. Бой и нанокостюм

BotCombat: видимость и враг → прицеливание → штатная стрельба, reload и боезапас.
Проверить урон в обе стороны, kill credit и shot validation. Добавить BotBrain,
ограниченную реакцию, выбор цели и режимы костюма с реальным расходом энергии.

## 5. Power Struggle пешком

BotGameMode/PSBotLogic: команда и respawn → одна цель захвата → одна проверенная
покупка за реальные Prestige Points. Проверить отказ при нехватке средств,
принадлежность объекта, завершение матча, совместную игру людей и ботов.

## 6. Расширение

Профилирование числа ботов, карты и маршруты, командные задачи, транспорт,
длительные dedicated-прогоны. Возможность server-only установки должна проверяться
отдельно; серверная симуляция сама по себе этого не гарантирует.
